# Blender outline cat

Transparent linework rendered from the user's approved **Outline Cat.blend**
animation (Outline Copy). The cat interiors and background have no fill.

- `outline-cat.webp`: original three-second loop, 768 × 1152.
- `outline-cat-right.webp`: the same 72 Blender frames starting at frame 10,
  so the two cats emphasize opposite front paws.
- Matching PNGs provide still poses for mobile, reduced motion and hidden views.

Both WebPs loop indefinitely and preserve the original RGBA linework losslessly.
Identical held frames are combined while preserving the three-second duration.
The website uses native images; Blender and WebGL are not needed at runtime.
